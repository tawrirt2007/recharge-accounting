🎨 توليد أيقونات PWA

اضغط على "رسم الأيقونات" لتوليد جميع أحجام الأيقونات المطلوبة للتطبيق

📋 تعليمات تحويل التطبيق إلى APK

  1. طريقة 1 - PWA Builder (الأبسط، لا تحتاج كمبيوتر):
    • ارفع ملفات المشروع (HTML, manifest.json, sw.js, icons) إلى GitHub Pages أو Netlify أو Vercel
    • اذهب إلى PWABuilder.com
    • أدخل رابط موقعك واضغط "Start"
    • اختر "Android" ثم "Generate" لتحميل ملف APK/AAB
  2. طريقة 2 - Bubblewrap (تتطلب Node.js): 
    npm i -g @bubblewrap/cli
bubblewrap init --manifest=https://your-domain.com/manifest.json
bubblewrap build
  3. طريقة 3 - Capacitor (للمطورين): 
    npm init @capacitor/app
npm install @capacitor/core @capacitor/android
npx cap add android
npx cap sync
npx cap open android
    ثم في Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s)
  4. طريقة 4 - WebViewGold (مدفوع، سهل): اشترِ قالب WebViewGold لـ Android، ضع رابط موقعك، وصدّر APK مباشرة.

ملاحظة مهمة: لتعمل ميزات PWA الكاملة (التثبيت، العمل أوفلاين)، يجب تشغيل الموقع عبر HTTPS. GitHub Pages و Netlify و Vercel توفر HTTPS مجاناً.
